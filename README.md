# 럭키팡 숫자던전 - 곱셈구구편

초등학교 2학년 곱셈구구 학습 흐름을 바탕으로 만든 독립형 카드 배틀 프로젝트입니다. 문제는 0의 곱, 1단과 2단부터 9단까지의 한 자리 수 곱셈 범위에서 출제됩니다.

## 학습 순서

1. 두·다섯 단 마을: 2단과 5단
2. 세·여섯 단 숲: 3단과 6단
3. 네·여덟 단 협곡: 4단과 8단
4. 일곱·아홉 단 동굴: 7단과 9단
5. 1·0과 곱셈표 성채: 1단, 0의 곱, 곱셈표

메인 캠페인을 완주하면 **도전의 탑**이 열립니다. 도전의 탑에서는 결과 범위, 기준값 비교, 같은 결과, 일의 자리, 자릿수 합 문제를 풀어 누적 점수를 채우고 다음 층에 오릅니다. 최고 층과 최고 점수는 이 브라우저에 저장됩니다.

각 구역은 대화형 개념학습과 보스 전투로 구성됩니다. 보스를 물리치거나 집중력이 모두 소진될 때까지 전투가 이어지며, 전투는 `퀴즈 → 행동력 보상 → 카드 액션 → 보스 행동` 순서로 진행됩니다. 문제는 시드 기반으로 무작위 생성되며 보기 5개 중 정답 3개, 오답 2개, 럭키 정답 1개, 폭탄 오답 1개를 보장합니다. 모든 선택지에는 정답 근거 또는 오개념 해설이 포함됩니다.

## 실행

```bash
npm install
npm run dev
```

## 의존성 관리

`package-lock.json`은 검수·배포 환경에서 같은 라이브러리 버전을 설치하기 위한 파일입니다. 납품·CI 환경에서는 아래 명령으로 lockfile 기준 설치를 사용합니다.

```bash
npm ci
```

의존성을 변경할 때만 `npm install`을 실행하고, 변경된 `package-lock.json`을 함께 관리합니다.
